📌 Project Overview:
This project is an interactive Excel dashboard designed to analyze and visualize online shopping sales data.The dashboard provides key business insights such as sales performance, customer trends, and product analysis to support data-driven decision-making.
It is built using Microsoft Excel with pivot tables, charts, and slicers for dynamic analysis.

🎯 Objectives:
1. Analyze online shopping sales data.
2. Identify sales trends and patterns.
3. Track key performance indicators (KPIs).
4. Provide a clear and interactive dashboard for business users.

🧰 Tools & Technologies Used:
1. Microsoft Excel: Pivot Tables,  Pivot Charts, Slicers & Filters, Conditional Formatting.
2. Data Cleaning & Preparation.
3. Dashboard Design & Visualization.

📈 Key Features:
1. Interactive dashboard with slicers.
2. Sales analysis by: Product category, Time period, Region / customer segment.
3. Key KPIs: Total Sales, Total Orders, Average Order Value.
4. Clear visualizations for quick insights.

📂 Dataset Description:
The dataset includes information such as:
1. Order ID
2. Order Date
3. Product Category
4. Sales Amount
5. Quantity
6. Customer / Region details

🔍 Key Insights:
Some insights that can be derived from the dashboard:
1. Identification of top-performing product categories.
2. Seasonal trends in online sales.
3. High-revenue customer segments.
4. Sales growth or decline across different periods.
